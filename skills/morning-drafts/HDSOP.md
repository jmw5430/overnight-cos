# Morning drafts: the map

**What it is for.** The operator wakes up to replies already written in their own voice, plus one short list of decisions on their phone.

**The flow.** Learn from last week's edits, then for each reply owed: read the thread, find the operator's recorded decision, draft in their voice, style-check, save. Then raise the decision cards and text the operator once.

**Where it branches.** No recorded decision means no draft; the card asks the one question instead. An existing newer draft is left alone; an older one is replaced.

**What stays human.** Sending every draft. Every decision the drafts could not find written down.

**What it never does.** Send, reply, forward, post, invent a fact, or use a personal calendar event's title.
